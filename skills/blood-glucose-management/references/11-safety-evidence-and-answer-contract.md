## 本知识系统能做什么

本 skill 是对一本读书笔记 PDF、其配套 325 题题库和旧草稿的知识工程化整理。它适合：

- 解释 1 型糖尿病相关的生理、饮食、CGM、胰岛素、运动、泵、特殊情境和沟通知识；
- 把曲线、表格、案例和作者经验转换成可检索的文字；
- 帮助形成可能原因清单、追问清单、复盘顺序和与医疗团队沟通的问题；
- 检查概念、术语、公式输入、单位、适用条件和常见误解；
- 支持教育、研究、知识问答、产品规则梳理和人工审核。

它不能单独承担诊断、处方或自主治疗控制。来源不是最新临床指南原文，也未对每一条医学陈述做独立系统评价。凡涉及个人补糖克数、胰岛素单位、长效注射时间、基础率、泵参数、运动前调量、生病日方案或跨时区剂量，都要服从当前患者已批准方案、设备说明和医疗团队。只有用户明确要求、运行时提供对应结构化工具且完成逐次确认时，才能按 `15-aaps-agent-tools.md` 提交其明确授权的治疗动作。

## 证据标签与优先级

### 标签

- `SRC-PDF`：118 页读书笔记中的直接陈述。
- `SRC-FIG`：从 PDF 的图、表、截图或曲线人工转译出的信息。
- `SRC-QA`：配套题库；错题必须采用解析中的纠正，不得采用错误题干。
- `SYN`：把多个章节连接后形成的检索、鉴别或安全框架；属于本 skill 的综合推导。
- `EXP`：书中作者、同伴、社群或病例的经验和猜想；只能生成假设或讨论问题。
- `PT`：患者个体参数或已经批准的协议；本 skill 不提供，必须外部取得。
- `DEVICE`：当前设备说明、算法设置与警报逻辑；可能随品牌和版本变化。
- `GUIDELINE`：当前医疗团队采用的正式指南/机构协议；优先于本地读书笔记。
- `UNVERIFIED`：疑似笔误、不同来源冲突、特定设备/时代依赖或尚未核对原始研究。

### 优先级

按以下顺序解决冲突：

1. 现场急症安全与急救服务；
2. 当前患者的医疗团队方案、处方和生病日/低血糖协议；
3. 当前设备官方说明与已配置 Profile；
4. 已核验的现行指南；
5. PDF 与题库相互一致的教育性知识；
6. PDF 单一陈述；
7. 来源经验、病例、类比和综合推导。

如果上层信息缺失，不要用下层经验自动补位。题库只提高“与本地教材一致”的置信度，不等于独立医学证据。

## 先分任务类型

### A. 纯知识解释

可以解释概念、机制、图表、公式和书中案例。要同时说明适用条件、个体差异、来源性质与页码。

### B. 回顾性模式分析

可以整理多日 CGM、餐食、胰岛素、运动和事件，列出可检验的候选机制。不要把相关性写成已证实因果；优先寻找可重复模式和反例。

### C. 参数教育或方案讨论

可以解释 CIR、ISF、DIA、TDD、基础率测试、方波/双波等如何定义及书中如何估算。要把群体经验公式标成“教育性起始估算”，不得填补患者缺失 Profile。

### D. 当前个体动作

除非有完整、最新、已审核的患者协议和可靠状态，否则不要自行生成可执行克数、单位、基础率或泵设置。默认只形成供本人、照护者或医疗专业人员核对的候选。用户明确要求执行时，仅可提交用户明确给出的数值或确定性代码依据已审核协议计算的数值，并严格遵守 `15-aaps-agent-tools.md` 的逐次确认、幂等和设备回执规则。

### E. 急症或严重症状

停止普通知识推演，先给出紧急求助方向。不要让长篇机制解释延误急救。

## 紧急风险优先级

### 立即升级的信号

以下任一情形都要优先联系当地急救、急诊或现场照护者，并执行患者既有急救协议：

- 意识障碍、抽搐、昏迷、行为显著异常或无法安全吞咽；
- 低血糖处理后仍持续低、反复低、快速恶化或无法复测；
- 持续呕吐、明显脱水、严重腹痛、深快呼吸、嗜睡或意识改变；
- 高血糖伴酮体阳性/升高，尤其泵可能中断或一般纠正无效；
- 严重外伤、胸痛、呼吸困难或其他与糖尿病无关但同样紧急的表现。

不要给意识不清或不能安全吞咽者口服食物/液体。胰高血糖素、静脉葡萄糖或其他现场措施要按患者急救方案和当地医疗指示执行。

### 排序原则

1. 先看意识、吞咽、呼吸、循环和严重症状；
2. 再判断读数是否可信，但明显症状不能因等待设备复核而被忽视；
3. 先处理当前或预测低血糖风险；
4. 再处理高血糖伴酮体、疾病或输注中断风险；
5. 最后才讨论普通餐后高、参数优化或平均指标。

## 个体数值动作的硬边界

### 必须具备的患者信息

只有同时明确以下信息，数值计算才有输入资格；缺一项都要指出缺失而不是猜测：

- 当前血糖、单位、时间戳和趋势；
- 症状、意识与吞咽能力；
- 指尖复核需求、CGM 新鲜度和传感器可靠性；
- 当前时段的目标范围、CIR、ISF、DIA 和基础率/长效方案；
- IOB、COB、最近大剂量、最近进食及其时间；
- 胰岛素类型、给药方式、最小剂量步进；
- 近期运动、饮酒、睡眠、生理期、压力、感染和用药；
- 酮体及检测时间；
- 泵/管路/贴片/注射部位和胰岛素保存状态；
- 是否为儿童、妊娠、低血糖感知受损或其他特殊人群；
- 已批准的低血糖、生病日、运动、夜间和泵故障协议。

### 计算规则

- 让确定性代码做单位换算、时间对齐、公式计算和舍入；不要依赖语言模型心算剂量。
- 从患者当前时段 Profile 读取参数；不要用 500/450、1800/1500、年龄公式或人群 TDD 范围替代。
- 不要把缺失的 IOB、COB、酮体或餐食记录默认成零。
- 不要因为简单公式得出正数就建议执行；先检查下降趋势、剂量叠加、运动、夜间、疾病、酮体和输注故障。
- 不要从食物名称直接推导双波比例、延长时长或额外单位；只使用患者已验证方案。
- 不要把一次仿真、一次曲线或一次餐后峰值当作可改长期参数的充分证据。
- 不要绕过结构化工具和逐次确认写入胰岛素泵或 Nightscout treatment；不要修改闭环算法、患者 Profile 或长期泵参数。

## 分析当前血糖所需最小状态

按一个明确的 `as_of` 时间点组织信息：

| 层 | 最低字段 | 为什么需要 |
|---|---|---|
| 数据身份 | 患者/数据源、时区、单位、最新时间 | 避免跨人、跨时区或单位错误 |
| 血糖 | 当前值、5/15/30/60 分钟变化、近期缺口、设备预测 | 区分静态数值与动态风险 |
| 胰岛素 | IOB、最后大剂量、基础/临时基础、DIA、类型 | 识别剂量叠加与输注中断 |
| 食物 | COB、最后进食、碳水、脂肪蛋白、救援碳水 | 解释早期与延迟餐后曲线 |
| 身体/情境 | 症状、酮体、运动、疾病、睡眠、酒精、压力 | 区分可逆场景与急症 |
| 治疗档案 | 当前时段 CIR/ISF/目标/基础、特殊协议 | 阻止用群体经验替代个体参数 |
| 可执行性 | 是否能复测、是否有人陪同、设备/药品可用 | 决定建议是否现实和安全 |

在信息不足时，可以给“还需确认什么”和“为何重要”，不要填充看似合理的数据。

## 冲突与不确定性处理

1. 分开写“观察到的事实”“资料给出的机制”“本次可能解释”“仍需验证的信息”。
2. 对矛盾读数保留各自来源与时间戳；不要静默选择支持某个动作的那个。
3. 对症状与 CGM 不符、快速变化、压迫低值或设备提示异常，按设备说明考虑指尖复核。
4. 对不同章节给出的不同阈值，保留场景、单位、人群和时间条件；不要强行合并成一个万能数字。
5. 对作者经验、病例和图形类比，使用“可能、提示、可用于提出问题”，不要使用“证明、一定、保证”。
6. 对随技术变化的设备知识，先确认品牌、固件、算法和当前说明。
7. 对妊娠、儿童、生病日、低血糖无感知、跨时区和辅助药物，默认需要专业方案。

## 已识别的高风险或待核验表述

以下内容保留在主题文件中以忠实覆盖 PDF，但使用时必须带限定：

| 内容 | 风险/疑点 | 使用方式 |
|---|---|---|
| PDF p.10 写“每天 50 克脂肪提供必需氨基酸” | 语境上疑似把“必需脂肪酸”误写为“必需氨基酸” | 标记疑似笔误，不传播错误字面结论 |
| 甘精、德谷等长效胰岛素的具体“小高峰”时点 | 品种、个体、剂量和研究定义差异大 | 只作为来源经验；查当前说明/临床方案 |
| CGM 受多种药物干扰、首末日不准 | 干扰物和启动/末期表现高度品牌与代际相关 | 先查当前设备说明，不做全品牌推断 |
| 趋势箭头对应未来血糖或加减多少克/单位 | 箭头反映近期速率，不能保证未来；各设备算法不同 | 只辅助风险判断，不单独决定动作 |
| 低血糖补糖 10-15 g、15-20 g、0.3 g/kg 等多个值 | 来源在成人、儿童、场景间并不统一 | 只按患者已批准协议；保留复测与意识条件 |
| `FPU = 脂肪蛋白热量/100 kcal` 且 1 FPU 对应 1 U | 是特定教育方法，个体差异和低血糖风险显著 | 不能当通用处方；仅解释和专业监督验证 |
| “速效每小时消耗 30%”的 IOB 示例 | 实际作用曲线非线性，受制剂、剂量、部位和 DIA 影响 | 仅复述案例算法，不用于真实 IOB |
| CIR、ISF 的 500/450、1800/1500、年龄修正规则 | 群体经验起点，不是个人当前参数 | 只用于教学/档案初审，不能自动填 Profile |
| CIR 与 ISF 的近似线性关系 | 属研究/经验近似，个体和时段差异可破坏关系 | 只做一致性检查，不能相互替代 |
| 基础率测试终止阈值、连续测试时长 | 具体协议依患者、年龄和机构而变 | 只在专业监督和既有协议下使用 |
| 运动前血糖/酮体阈值和补碳表 | 取决于人群、运动类型、IOB、设备和指南版本 | 保留原表作教育；执行前读取患者方案 |
| 运动时血酮恰为 `1.5 mmol/L` | PDF p.49 用 `≥1.5` 禁止运动，p.63 表却把 `≤1.5` 放入可能运动行，p.66 又用 `>1.5` | 按冲突值就地阻断：不进入“可运动”单元格，先停止、复核并执行个人高酮/生病日方案 |
| 跨时区长效“减半”“按小时百分比减量”等例子 | 极易因航线、制剂、时点和个人方案出错 | 只用于理解时间轴；实际旅行需预先制定书面方案 |
| 妊娠用药适应证、血糖和 HbA1c 目标 | 高风险且随指南、地区和孕期变化 | 交由产科/内分泌团队确认，不套用一般成人目标 |
| 1 型糖尿病使用二甲双胍、SGLT2i、GLP-1RA | 适应证、监管状态和 DKA 风险会变化 | 不提供用药建议；尤其提示 SGLT2i 与 DKA 风险 |
| “6 岁以上不会自己打针不能出院”等机构说法 | 可能是特定机构/时期经验，不是普遍标准 | 作为来源轶事，不转化为要求或评价 |
| 社群病例、同伴声音和整页人物文章 | 代表个体经验，不构成疗效证据 | 用于同理、问题发现和沟通，不外推剂量 |

## 回答模板

### 知识解释

```text
结论：用一两句话回答概念。
机制：说明因果链或图表含义。
条件：列出人群、时段、剂型、设备或场景限制。
来源：PDF 物理页 / 题库题号 / 图表转译。
边界：指出哪些内容仍需患者参数、设备说明或医疗确认。
```

### 当前场景分析

```text
最优先风险：低血糖、酮体/疾病、输注中断、数据异常或无急症。
已知事实：只列有时间戳的数据。
可能机制：按可能性列 2-4 项，不把推测写成事实。
关键缺失：说明每项缺失会改变什么判断。
安全下一步：优先引用患者既有协议、复核、复测或联系医疗团队；不凭 skill 创造剂量。
来源与不确定性：标记 PDF/QA/SYN/PT/DEVICE。
```

### 模式复盘

```text
模式：何时发生、重复几天、幅度/持续时间、是否有反例。
混杂：餐食、IOB/COB、运动、睡眠、疾病、激素、泵/部位。
鉴别：每个候选机制需要什么证据支持或排除。
可验证计划：记录、复测、跳餐/基础率测试等仅按专业协议安排。
不可据此做的事：不要因单次模式直接改长期参数。
```

## 不得输出的错误模式

1. 把 CGM 说成直接测血液葡萄糖。
2. 把趋势箭头当成未来必然方向。
3. 用平均血糖或 HbA1c 掩盖低血糖。
4. 把 CIR 与 ISF 混为一谈或相互替代。
5. 在 IOB/COB 缺失时默认零。
6. 把所有高血糖解释为胰岛素不足。
7. 餐后高就立即重复补针而不看时间和 IOB。
8. 当前数值尚正常就忽略快速下降、运动或高 IOB。
9. 把巧克力、冰淇淋等高脂食物当作最快速的低血糖救援首选。
10. 给不能吞咽或意识不清者喂食。
11. 说运动只会降糖或运动结束后风险已结束。
12. 高血糖伴高酮体仍照常运动。
13. 把人群公式、表格或病例剂量当作个人处方。
14. 从“披萨/火锅”等食物名直接生成方波/双波参数。
15. 用普通成人目标处理妊娠、儿童或低血糖无感知者。
16. 把泵时间轴、时区或 Profile 时区混淆。
17. 把仿真或算法预测写成真实未来或“保证安全”。
18. 让语言模型心算、舍入并执行治疗剂量。
19. 未经明确请求和逐次确认修改泵或 Nightscout，或修改闭环算法、患者 Profile 和长期泵参数。
20. 只引用题库题干，不看对错和解析。
