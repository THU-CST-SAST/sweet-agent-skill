## 最小读取路径

1. 先读 `11-safety-evidence-and-answer-contract.md`，判断问题是知识解释、回顾分析、个体参数讨论还是急症风险。
2. 按下表读取一个或多个完整主题文件；不要只截取命中行，因为多数数值的适用条件写在同一节的前后文。
3. 涉及名词、单位或公式时，再读 `12-glossary-formulas-and-numeric-reference.md`。
4. 涉及一个现象的多种可能原因时，再读 `13-cross-topic-reasoning-and-scenario-index.md`。
5. 需要核查易错命题或原书印刷页时，在 `10-question-bank-verification-cards.md` 中搜索；必须同时读“判断”和“解析”。
6. 需要证明 PDF 是否逐页覆盖、区分物理页与原书页时，读 `00-source-map-and-page-coverage.md`。
7. 需要核对 PDF 原句、图片页文字或精编主题文件中的遗漏时，定点检索 `14-pdf-full-text-and-visual-ocr-transcript.md`；只打开命中页附近，不要整份加载。
8. 涉及 AAPS、Nightscout、泵状态、治疗历史或设备动作时，读取 `15-aaps-agent-tools.md`；先区分只读与写入工具，再检查运行时是否真正提供对应工具。

## 跨文件检索方法

在 skill 根目录运行全文检索时，优先使用窄而可组合的查询：

```bash
rg -n "关键词|同义词" references/
rg -n "PDF p\.(4|5|6)" references/
rg -n "Q(143|144|145)" references/10-question-bank-verification-cards.md
rg -n "经验|待核验|患者参数|急症" references/
rg -n "^## PDF p\.104｜|关键词" references/14-pdf-full-text-and-visual-ocr-transcript.md
```

推荐组合词：

- `低血糖 + IOB + 运动 + 睡前`
- `高血糖 + 酮体 + 泵 + 输注`
- `高脂 + 蛋白 + 延迟 + 双波`
- `黎明 + 生长激素 + 皮质醇 + 基础率`
- `CGM + 时滞 + 症状不符 + 指尖`
- `妊娠 + TIR + 目标范围`
- `儿童 + 注射 + 恐惧 + 同理`

不要只读取 `rg` 命中行。至少打开命中小节；涉及数值时打开整个主题文件及 `11-*`。

## 来源与标签解释

- `PDF p.N`：118 页读书笔记 PDF 的物理页。
- `原书 P.N`：笔记/题库提到的书本印刷页。
- `QNNN`：配套题库题号。
- `来源陈述`：忠实整理原资料，不代表已按最新指南独立核验。
- `图表转译`：从页面中的表、曲线、流程图或截图改写为文字。
- `来源经验`：作者/同伴的经验、类比、推测或策略，不可自动推广。
- `综合推导`：由多个章节连接得到的分析框架；不是原书逐字结论。
- `患者参数`：只能来自患者当前、已审核的治疗方案或医疗团队。
- `待核验`：疑似笔误、表述冲突、时代/设备依赖或需要原始指南确认。
